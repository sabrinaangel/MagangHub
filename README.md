MagangHub adalah platform web berbasis CodeIgniter 4 yang dirancang untuk membantu mahasiswa dan pelajar menemukan program magang berkualitas.

Fitur utama:
- Manajemen program magang
- Manajemen artikel & tips
- Dashboard admin (CRUD data)
- Sistem login admin
- Tampilan modern dan responsif

Platform ini juga menyediakan halaman publik untuk menampilkan informasi program, artikel, serta halaman tentang dan kontak.
